# Student Welfare Business Process – ADONIS Project

## 📘 Μάθημα
**Διαχείριση και Ανάπτυξη Επιχειρηματικών Πληροφοριακών Συστημάτων και Ροών Εργασίας**

## 🎯 Σκοπός
Στόχος του project είναι η αποτύπωση του **πλήρους επιχειρησιακού μοντέλου** της Φοιτητικής Μέριμνας σε περιβάλλον **ADONIS BPM Tool**, χρησιμοποιώντας όλα τα απαραίτητα types:

- Company Map  
- Business Processes  
- Sub-processes  
- Working Environment  
- Document Model  

Τα μοντέλα είναι πλήρως παραμετροποιημένα ως προς τους χρόνους, τα κόστη και τα σενάρια απόφασης.

---

## 🗺️ Company Map
Ο κεντρικός “χάρτης” του συστήματος περιλαμβάνει:

- Τη Φοιτητική Μέριμνα
- Τη Στέγαση
- Τη Σίτιση
- Την Αποδοχή ή Απόρριψη Αίτησης

Κάθε επιλογή οδηγεί σε υποδιαγράμματα μέσω trigger, ανάλογα με την πορεία της διαδικασίας.

---

## 📄 Document Model
Το μοντέλο εγγράφων περιλαμβάνει:

- Αίτηση Σίτισης / Στέγασης
- Βεβαίωση Σπουδών (γραμματεία)
- Πιστοποιητικό Οικογενειακής Κατάστασης
- Πιστοποιητικό Εντοπιότητας (ΚΕΠ)
- Εκκαθαριστικό Εφορίας
- Διαθέσιμα Δωμάτια / Δικαιολογητικά για Επίδομα

---

## 🔄 Business Processes

### 🧩 Μέριμνα
1. Προσέλευση φοιτητή  
2. Επεξεργασία αίτησης (γραμματεία)  
3. Απόφαση → Σίτιση / Στέγαση  
4. Trigger → Σχετικό υποδιάγραμμα  
5. Παράλληλες ενέργειες  
6. Τέλος  

### 🥗 Σίτιση
1. Απόφαση  
2. Ενημέρωση φοιτητή για δικαιολογητικά  
3. Υποδιαδικασία – Συμπλήρωση δικαιολογητικών  
4. Παρουσίαση και έλεγχος  
5. Trigger επιστροφής αν παρέλθει διορία  

### 🛏️ Στέγαση
1. Έλεγχος δωματίων  
2. Αν υπάρχουν → Ανάθεση  
3. Αν όχι → Ενημέρωση για επίδομα  
4. Συγκέντρωση δικαιολογητικών  
5. Παρουσίαση και έλεγχος  
6. Trigger επιστροφής αν παρέλθει διορία  

### ✅ Θετική Απόφαση
1. Υπογραφή Προέδρου  
2. Παράλληλες ενέργειες  
3. Ενημέρωση συστήματος  
4. Ενημέρωση φοιτητή  
5. Τέλος  

### ❌ Απόρριψη Αίτησης
1. Ενημέρωση συστήματος  
2. Ενημέρωση φοιτητή  
3. Τέλος

## 🧑‍💼 Working Environment

4 Ρόλοι:

- Υπάλληλος Γραμματείας
